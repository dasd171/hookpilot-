# Bill of materials — bench prototype (ESTIMATES)

`bom.csv` columns: category, part, qty, unit_price_usd, price_status, extended_usd, sourcing_notes.

**Every price is an ESTIMATE** (typical hobby/online retail ranges as of late 2026, single units,
before shipping/tax). Nothing has been quoted or ordered. Part names are *candidates*; check each
datasheet before buying (HX711 output rate, servo IP rating and stall current, motor stall current vs
DRV8874 rating).
