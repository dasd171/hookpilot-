# Event record examples (SIMULATION)

Generated by the Python reference engine (`services/evidence-service`, generator `hookpilot-synth-v1`,
classifier `deterministic-baseline-v1` firmware-port). All are labelled `source.mode = "simulation"`
and `actuation.simulated = true`; none describes a physical event.

| file | scenario / seed | what it shows |
|---|---|---|
| `bite.json` | bite / 1 | confirmed bite, hook-set + retrieval assist completed, `fish_landed: "unknown"` |
| `rejected_vibration.json` | rod_vibration / 1 | candidate rejected (oscillation count), no actuation |
| `safe_stop_motor_stall.json` | motor_stall / 1 | MOTOR_STALL during retrieval -> SAFE_STOP |
| `sensor_fault_stuck.json` | sensor_failure / 2 | sensor fault -> rejected_sensor_fault + SAFE_STOP |
| `observation_only_disarmed.json` | bite / 3 (disarmed) | bite confirmed but no actuation requested (IDLE) |
| `chain_example.jsonl` | 4 records, seed 5 | hash chain: each `prev_record_sha256` = previous `record_sha256` |
| `invalid/fish_landed_inferred.json` | — | schema violation: fish_landed outside the enum |
| `invalid/wrong_units.json` | — | schema violation: units must be "N" |
| `invalid/hash_mismatch.json` | — | schema-valid but `record_sha256` no longer matches (edited after sealing) |

Validate: `python packages/event-schema/validate.py packages/event-schema/examples/*.json --hash`
and `python packages/event-schema/validate.py packages/event-schema/examples/chain_example.jsonl --hash --chain`.
Replay any of them: `python -m evidence_service replay <file>` (from `services/evidence-service`).
